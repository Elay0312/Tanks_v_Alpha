# Tanks_v_Alpha

Аркадная игра в жанре "танковый бой" с видом сверху, управлением с клавиатуры и динамической прокруткой карты. Игрок управляет танком, уничтожает врагов, собирает бонусы и исследует процедурно генерируемый мир.

## 🎯 Особенности

- Управление танком игрока (WASD)
- Динамическая камера, следующая за игроком
- Вражеские танки с ИИ
- Система стрельбы и разрушаемого окружения
- Бонусы: ускорение, лечение, дополнительный боезапас
- Различные типы препятствий (кирпич, бетон, вода)
- Анимации взрывов и эффектов

## 🎮 Управление

### Управление танком (для игрока)
| Клавиша | Действие |
|---------|----------|
| `W` | Движение вверх |
| `S` | Движение вниз |
| `A` | Поворот налево |
| `D` | Поворот направо |
| `Space` | Стрельба |

### Управление камерой (для отладки/навигации)
| Клавиша | Действие |
|---------|----------|
| `↑` | Сдвиг камеры вверх |
| `↓` | Сдвиг камеры вниз |
| `←` | Сдвиг камеры влево |
| `→` | Сдвиг камеры вправо |

🎲 Игровая механика
Танк игрока
Начинает с определённым количеством здоровья и боезапаса

Может уничтожать вражеские танки

Собирает бонусы, выпадающие при уничтожении врагов

При уничтожении игра заканчивается (пока не реализован экран поражения)

Вражеские танки
Автоматически перемещаются по карте

Стреляют в направлении игрока

Могут быть уничтожены попаданием снаряда

Типы препятствий
Тип	Разрушаемость	Проходимость
Кирпич	✅	❌
Бетон	❌	❌
Вода	❌	❌ (только для игрока?)
Грунт	❌	✅
Бонусы
Дополнительные снаряды (MISSLE) - увеличивает боезапас

Лечение (HEAL) - восстанавливает здоровье танка

Ускорение (FUEL_BOOST) - временно увеличивает скорость

Скорость (SPEED_BOOST) - повышает скорострельность

🏗️ Архитектура проекта
Проект состоит из нескольких модулей:

main.py - точка входа, обработка ввода, главный игровой цикл

world.py - управление картой, камерой, отрисовка окружения

tanks_collection.py - логика танков (игрок и враги)

Missiles_collection.py - логика снарядов и столкновений

Texture.py - загрузка и кэширование текстур

⚙️ Технические детали
FPS: 60 кадров в секунду

Используется Tkinter Canvas для отрисовки

Динамическая камера, центрированная на игроке

Коллизии обрабатываются на уровне тайлов (размер тайна не указан, предположительно 32x32 или 40x40)

Векторная система движения (направление + скорость)
